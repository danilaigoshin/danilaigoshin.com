Problem & ownership

One workspace for authoring, compilation, and AI review.

Scientific writing spans source files, compilation diagnostics, PDF inspection, and AI assistance. Bringing those tasks into one collaborative interface meant editor state, preview rendering, and assistant feedback had to stay clear and coordinated side by side.

Product context
Scientific authoring, compiled document review, and AI assistance inside one collaborative workspace.
Operating constraint
Keep source files, compile feedback, document preview, and assistant state understandable together.
My ownership
Frontend ownership across authoring, compiled preview, AI chat, analytics, and admin tooling.
Key decision
Connect source editing, compile errors, PDF.js review, and AI actions in one unified workflow.

Implementation

How the workflow came together.

The frontend connects four core product surfaces within a single workspace: source editing, compiled PDF review, model-aware AI chat, and operational tooling.

Authoring

Support LaTeX and Typst editing with reliable saves.

Built source editing in Monaco with keyboard shortcuts, autocomplete, minimap controls, auxiliary TeX files, plain-text fallback, and reliable save handling.

Compiled output

Map compile errors directly back to source.

Connected PDF.js previews for LaTeX and Typst with compile errors mapped back to source and graceful fallback states so scientists can resolve failures inside the workspace.

AI workflow

Expose model controls and reusable actions in chat.

Implemented AI research UX with per-message model selection, reasoning blocks, token labels, inline errors, and reusable response actions.

Product operations

Deliver analytics, admin views, and localization together.

Shipped Amplitude instrumentation, environment-aware runtime configuration, paginated admin tooling, and EN/RU localization.

Result & stack

Scientists can edit source, review compiled output, and act on AI feedback without switching tools.
