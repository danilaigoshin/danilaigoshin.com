Problem & ownership

Fast support operations without breaking live integrations.

Returning to Smartway for a second engagement, I built an embeddable support widget and ticket-management workspace for corporate travel teams handling live customer conversations, file attachments, and operational request routing.

Product context
Real-time customer communication, ticket routing, uploads, and operational request handling.
Operating constraint
Keep long threads responsive while public widget integrations and existing authentication continued to work.
My ownership
Widget architecture, public integration API, performance work, HMAC migration, uploads, and routing.
Key decision
Virtualize long message threads and migrate authentication to HMAC with backward compatibility.

Implementation

How the widget and workspace came together.

Engineering work spanned four areas: clear boundaries for host integrations, runtime performance in long conversations, backward-compatible authentication, and day-to-day ticket workflows.

Architecture

Ship an embeddable widget behind a public integration API.

Structured the embeddable support widget and ticket workspace with Feature-Sliced Design, domain-driven modules, and a public integration API.

Performance

Virtualize long threads to cut render work.

Introduced list virtualization to reduce render work in operational threads exceeding 1,000 messages so conversations stay responsive while scrolling.

Integration safety

Migrate authentication to HMAC without breaking consumers.

Introduced HMAC authentication while preserving backward compatibility for existing host integrations.

Operational scope

Validate uploads and route tickets by travel team.

Delivered validated drag-and-drop uploads for 15+ file formats alongside ticket categorization and routing by travel team.

Result & stack

70% faster rendering in threads with more than 1,000 messages.

List virtualization kept long support threads smooth, HMAC authentication rolled out without breaking existing consumers, and support operations gained multi-format uploads and travel-team routing. Alongside delivery, I introduced practical LLM workflows for architecture, review, and testing, wrote guidelines, and trained the team.

Measurement note. The performance result refers to rendering long conversations after list virtualization, not a general application-speed or business-impact measurement.
